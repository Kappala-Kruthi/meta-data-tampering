An automated digital forensics framework and web platform for extracting EXIF, IPTC, and XMP structures, identifying chronological inconsistencies, detecting image editing signatures, and conducting differential paired comparisons.

Source Code Repository Author Profile Forensic Methodology Guide
Problem Statement
The evidentiary challenge of digital media

Digital photographs are increasingly submitted as legal, journalistic, and intelligence evidence. However, modern photo-editing software and command-line utilities allow attackers to effortlessly alter capture dates, camera models, GPS coordinates, and image pixels without visible distortions. Establishing authenticity requires rigorous, verifiable metadata extraction and rule-based anomaly detection.

Project Objectives
Core technical deliverables achieved
  • Automate deep metadata extraction using Phil Harvey's ExifTool engine.
  • Implement chronological inconsistency rules (ModifyDate vs DateTimeOriginal).
  • Detect third-party editing signatures (Photoshop, GIMP, Canva, ExifTool itself).
  • Perform two-file differential comparisons (added, missing, changed tags).
  • Distinguish intentional tampering from benign social media compression (Pinterest, WhatsApp).
  • Compute SHA-256 cryptographic digests for tamper-evident digital custody.
Technical Architecture & Stack
Verified software components and libraries
Metadata Extraction

Limitations & Future Roadmap
Transparent academic boundary analysis
Current Academic Boundaries:

Without a verified reference copy or trusted sensor fingerprint, complete absence of metadata (as seen in web-scraped images) cannot definitively prove or disprove editing. The platform accurately labels such cases as Inconclusive rather than issuing false-positive determinations.

Future Enhancements:

1. Photo Response Non-Uniformity (PRNU) sensor noise pattern matching.
2. Machine learning classification of double-JPEG compression grid artifacts.
3. C2PA (Coalition for Content Provenance and Authenticity) manifest cryptographic parsing.
